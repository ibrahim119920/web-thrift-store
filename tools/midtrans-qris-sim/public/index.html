QRIS Simulator Midtrans Sandbox

Sandbox only

Dua jenis QR yang berbeda

  • QR kecil berisi URL (disediakan halaman pembayaran storefront saat mode sandbox). Isinya https://api.sandbox.midtrans.com/v2/qris/<uuid>/qr-code. Ini yang membuat alur scan → bayar berjalan penuh.
  • Gambar QRIS besar berisi payload EMVCo (000201…). Dari QR ini hanya bisa dibaca merchant, kota, dan nominal — tidak ada URL/UUID transaksi di dalamnya, jadi pembayaran tetap membutuhkan URL/UUID dari respons QRIS Core API.
  • Simulator resmi Midtrans hanya menerima QR Code Image URL, bukan payload QRIS. Itu sebabnya aplikasi ini meminta URL atau UUID.

1. Sumber QR

Contoh UUID saja: 11111111-1111-4111-8111-111111111111. Hanya domain api.sandbox.midtrans.com yang diterima.

Arahkan kamera ke QR kecil berisi URL qr-code. Kamera berhenti otomatis setelah QR terbaca.

Batasan penting

      
    
        
  • Hanya untuk sandbox. Server menolak semua domain selain *.sandbox.midtrans.com.
    • 
        
  • Tidak menerima, meminta, atau menyimpan server key / client key. Simulator Midtrans sendiri terbuka tanpa autentikasi.
    • 
        
  • Integrasi memakai scraping HTML simulator. Bila Midtrans mengubah halaman, parsing bisa rusak.
    • 
        
  • Kamera memerlukan localhost atau HTTPS serta browser dengan BarcodeDetector (Chrome/Edge). Firefox/Safari: gunakan unggah gambar atau tempel URL.
    • 
      

    

  


  

    
Alat testing lokal. Bukan bagian dari aplikasi storefront dan tidak terhubung ke database.
